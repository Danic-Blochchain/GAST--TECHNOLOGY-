H1
Lineage Hash
A recursive hash of the account's full history. Every new state transition is cryptographically chained to the previous one. Cannot be forged without controlling the entire chain.
H1 = SHA256(
  prev_H1 | tx_hash |
  sender | sequence
)
✓ SHA-256 — Quantum Resistant
H2
State Snapshot
A canonical serialization of an account's current UTXO set. Captures the exact balance state at the moment of transaction. Prevents any hidden or duplicate funds.
H2 = Serialize(
  sorted(UTXO_keys) +
  values
) → "key:val|key:val"
✓ UTXO Model — Fork Safe
H3
Integrity State-Lock
The primary double-spend protection. A domain-separated commitment that binds H1, H2, Sender ID, Sequence, and TX Hash into a single lock that cannot be replayed or manipulated.
H3 = SHA256(
  DOMAIN | H1 | GENESIS |
  sender | seq | H2 | tx
)
✓ Anti Double-Spend Lock
H4
VBlock Integrity Hash
Used for individual UTXO key generation and for the integrity hash of entire VBlocks. Chains all blocks together — any tampering with historical state breaks the H4 chain immediately.
H4 = SHA256(
  tx_hash | output_index |
  output_value
)
✓ VBlock Chain Integrity
